Student Grade Calculator

About

This is my first Python project. It calculates student marks, total, average, grade, and pass or fail result.

Features

- Accepts student name.
- Takes marks for five subjects.
- Calculates total marks and average.
- Displays grade and pass or fail result.
- Validates marks between 0 and 100.

Technology Used

- Python

How to Run

1. Install Python.
2. Download this repository.
3. Open the project folder in VS Code.
4. Run "student_grade_calculator.py".
